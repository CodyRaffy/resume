# Jackson Robot Run

An endless runner game built with **Phaser 3** and **TypeScript** where the player controls Jackson, dodging robots and collecting bots in a pseudo-3D perspective.

**Author:** Cody Raffensperger
**Purpose:** Portfolio project

## Play It

The game is deployed on Netlify and can be installed as a mobile app on your phone.

## Development

```bash
npm install          # Install dependencies
npm run dev          # Dev server at http://localhost:3000
npm run build        # Production build to dist/
npm run preview      # Preview production build
```

## Deploying to Netlify

The project is configured for Netlify with automatic builds.

### Setup

1. Push the repository to GitHub
2. Log in to [Netlify](https://app.netlify.com) and click **Add new site** > **Import an existing project**
3. Connect your GitHub account and select the repository
4. Configure build settings:
   - **Base directory:** (leave blank, or set to the project subfolder if in a monorepo)
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. Click **Deploy site**

Netlify will run `npm install` and `npm run build` automatically on each push to the connected branch. The build outputs `dist/index.html` and `dist/game.min.js`.

### Netlify Config

The project includes a `.netlify/netlify.toml` generated by Netlify with the build settings above. No manual configuration is needed beyond the initial setup.

## Installing as a Phone App (PWA)

The game is a Progressive Web App with offline support. It includes a web app manifest, service worker, and home screen icons so it can be installed like a native app.

### iPhone / iPad (Safari)

1. Open the deployed Netlify URL in **Safari**
2. Tap the **Share** button (square with arrow at the bottom of the screen)
3. Scroll down and tap **Add to Home Screen**
4. Optionally edit the name (defaults to "Robot Run")
5. Tap **Add**

The game will appear on your home screen with its own icon and launch in full-screen standalone mode (no browser chrome).

### Android (Chrome)

1. Open the deployed Netlify URL in **Chrome**
2. Tap the **three-dot menu** in the top right
3. Tap **Add to Home screen** (or **Install app** if prompted)
4. Tap **Add**

### PWA Files

The PWA functionality is provided by these files:

| File | Purpose |
|------|---------|
| `public/manifest.json` | Web app manifest (name, icons, display mode, theme color) |
| `public/sw.js` | Service worker for offline caching (network-first for HTML, cache-first for assets) |
| `public/icons/icon-192.png` | Home screen icon (192x192) |
| `public/icons/icon-512.png` | Splash screen icon (512x512) |
| `index.html` | Contains `<meta>` tags for iOS standalone mode and links to the manifest |

### Key PWA Meta Tags (in index.html)

```html
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="theme-color" content="#1a1a2e">
<link rel="manifest" href="./manifest.json">
<link rel="apple-touch-icon" href="./icons/icon-192.png">
```

## Controls

| Action     | Keyboard         | Touch            |
|------------|------------------|------------------|
| Move left  | Left arrow / A   | Swipe left       |
| Move right | Right arrow / D  | Swipe right      |
| Jump       | Up arrow / W / Space | Swipe up     |
| Slide      | Down arrow / S   | Swipe down       |

Tap fallback: tap left/right half of screen to move lanes.
